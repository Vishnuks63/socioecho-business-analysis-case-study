# User Stories and Acceptance Criteria

## Story 1 — Connect with relevant seniors and alumni
**User Story:** As a student, I want to connect with relevant seniors and alumni so that I can receive guidance on academics, placements, projects and career development.

**Acceptance Criteria**
- Student can search for relevant seniors/alumni.
- Student can view profile and expertise information.
- Student can send a connection request.
- Student can follow/connect with a senior or alumnus.
- Student can view connection status.

## Story 2 — Create a mentorship request
**User Story:** As a student, I want to create a mentorship request specifying the area where I need guidance so that I can connect with a suitable senior or alumnus.

**Acceptance Criteria**
- Student can submit a mentorship request.
- Student can specify Academic, Placement, Project or Career.
- Student can describe the guidance required.
- Relevant seniors/alumni can view the request.
- Relevant seniors/alumni can respond.
- Student can view the response.

## Story 3 — Share relevant resources
**User Story:** As an alumnus, I want to share academic and career resources with students so that I can help multiple students access useful information without responding individually.

**Acceptance Criteria**
- Alumni can upload/share a resource.
- Alumni can provide title and description.
- Resource can be categorized.
- Students can view/access shared resources.
- Source and category are visible.
- Unauthorized users cannot modify/delete resources.

## Story 4 — Conduct mentorship sessions
**User Story:** As a student, I want to participate in mentorship sessions with seniors and alumni so that I can receive detailed guidance through discussions and live interactions.

**Acceptance Criteria**
- Eligible users can create/join a session.
- Multiple participants can join where permitted.
- Topic/purpose is visible.
- Participants can communicate.
- Only authorized participants can access the session.
- Session can be closed by the appropriate participant/organizer.

## Story 5 — Publish events and opportunities
**User Story:** As an authorized event organizer, I want to publish relevant college events and opportunities so that students can discover useful academic, career and extracurricular activities.

**Acceptance Criteria**
- Authorized organizers can create an event/opportunity.
- Organizer can enter title, description, date, time and relevant details.
- Events can be categorized.
- Students can view published events.
- Students can access event details.
- Only authorized users can create/edit/remove published events.
