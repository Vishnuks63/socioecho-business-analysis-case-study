# Change Impact Analysis

## Change Request
**CR-01 — Allow multiple guidance categories**

### Current State
A student selects one guidance category when creating a mentorship request.

### Requested Change
A student can select multiple categories, such as Placement + Project + Career.

## Impact Assessment

| Area | Impact |
|---|---|
| Requirement | FR-06 must support multiple categories. |
| User Story | Create a mentorship request is affected. |
| Acceptance Criteria | Category selection and validation criteria must be updated. |
| Process | Request categorization changes from single-select to multi-select. |
| Matching | Mentor/resource matching must consider multiple categories. |
| UI | Category field changes to multi-select. |
| Data | Request records must support multiple categories. |
| Testing | Additional single/multiple-category scenarios are required. |
| Risk | A selected category could be ignored during matching. |
| Action | Update requirements, acceptance criteria, process, data handling and test coverage. |

## BA Approach
The analysis identifies what changed, which requirements and solution components are affected, and what documentation/testing needs to be updated.
