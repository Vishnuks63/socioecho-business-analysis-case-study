# Basic Data Analysis

## Purpose
Demonstrate routine descriptive data analysis using simulated mentorship-request data.

> **Important:** The dataset is simulated sample data created for this portfolio case study. It is not real SocioEcho user data.

## Questions Analyzed
1. Which category has the highest number of requests?
2. What is the average response time?
3. What percentage of requests were resolved?
4. Which mentor type handled the most requests?

## Findings
- Total requests analyzed: **30**
- Most requested category: **Placement**
- Average response time: **18.97 hours**
- Resolution rate: **80%**
- Most active mentor type: **Alumni**

## BA Interpretation
The simulated results suggest that placement-related guidance may deserve priority in future resource planning. The response-time measure can also be used as a starting point for discussing service expectations and process improvement.
