# Requirements Traceability Matrix

| Business Need | Functional Requirement | User Story | Acceptance Criteria |
|---|---|---|---|
| Students need suitable mentors | FR-02, FR-04 | Connect with relevant seniors and alumni | Search/view relevant profiles; send connection request; view status |
| Students need to communicate guidance needs | FR-05, FR-06 | Create a mentorship request | Submit request; select category; provide details |
| Alumni need an efficient way to help multiple students | FR-08 | Share relevant resources | Upload/share; categorize; students access resources |
| Students need structured mentorship interaction | FR-09 | Conduct mentorship sessions | Create/join; authorized access; communication |
| Students need centralized opportunities | FR-10 | Publish events and opportunities | Authorized creation; students view; access details |

## Purpose
The matrix maintains traceability from the business need through the solution requirement, user story and acceptance criteria. It can support requirement validation, testing and change analysis.
